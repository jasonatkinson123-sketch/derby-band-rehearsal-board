# Today's Band Rehearsals

An 8-bit daily rehearsal board for 6th, 7th, and 8th grade band.

## Current version

- Three independent rehearsal lists
- Automatic current-day heading
- Teacher editor with one item per line
- Browser storage so lists survive refreshes on the same device
- Responsive display for classroom screens, laptops, and phones

Open `index.html` to use it locally. The next deployment step will connect the board to a small shared data source so a ChatGPT action can publish lists from a spoken instruction.
