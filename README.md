# Today's Band Rehearsals

An 8-bit daily rehearsal board for 6th, 7th, and 8th grade band.

## Current version

- Three independent rehearsal lists
- Automatic current-day heading
- Live rehearsal data shared through `rehearsals.json`
- Automatic refresh every 30 seconds
- Responsive display for classroom screens, laptops, and phones

The board is designed to be updated conversationally. Give ChatGPT the sixth-, seventh-, and eighth-grade rehearsal plans; it updates `rehearsals.json`, and the public board refreshes automatically.
